# 遇见达内小师妹

那天，前端群里来了一个新人。她的群昵称后面带着“达内毕业”四个字，进群以后十分礼貌地发了一句：“各位前辈好，请大家多多指教。”

我看到这句话，立刻想起当年刚进群时的自己。那时候我也是这样小心翼翼，先观察大家聊天，等了半个小时才敢问：“请问小程序怎么写？”

我觉得这是一个建立前辈形象的好机会，马上回复：“欢迎小师妹，群里都是自己人，有问题随便问。”

小师妹问：“师兄，为什么大家都在说 JQ？”

我严肃地回答：“这是群里的历史文化，属于前端群的非物质文化遗产。”

她又问：“那 Vue 和 React 哪个更好？”

我说：“不要比较框架，要看场景。”

群友在旁边起哄：“鑫鹏大佬又开始讲大道理了。”

我没有理会，继续保持前辈风范：“技术只是工具，重要的是解决问题。”

小师妹问：“那为什么你们聊了半天，最后都在讨论谁去买奶茶？”

我认真解释：“这就是解决问题。前端群不光解决技术问题，也要解决大家的饮品需求。”

小师妹很快适应了群里的节奏。她从一开始的“请教各位前辈”，逐渐变成了“谁有招聘信息”“谁知道哪里好吃”“今晚有人开黑吗”。

有一天，她突然在群里问：“有没有人能帮我看一下这个报错？”

群里立刻刷屏。

“截图发出来。”

“控制台有没有红字？”

“把项目发我，我帮你看看。”

我正准备展现实力，她又补了一句：“算了，已经解决了，是电脑没插电。”

群里沉默了几秒，随后爆发出一片“恐怖如斯”。

我赶紧补充：“这说明小师妹排查问题的思路非常清晰，先从基础环境入手，值得大家学习。”

小师妹发了一个谢谢的表情。我看着那个表情，感觉自己作为前端群老人的使命又完成了一次：没有解决任何技术问题，但成功把一次没插电事故包装成了工程经验。
