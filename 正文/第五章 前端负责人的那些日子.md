# 前端负责人的那些日子

自从在群里混出一点名气以后，我发现大家对我的称呼逐渐发生了变化。

刚进群时，大家叫我“新来的”；后来因为我成功回答了一个“怎么让文字变红”的问题，大家开始叫我“新鹏”；再后来，我在群里连续发了三天 Vue 和 React 的对比文章，大家终于统一称呼我为“前端负责人”。

我第一次看到这个称呼时，正在群里抢红包。手一抖，红包没抢到，反而点开了自己的头像。我盯着“前端负责人”这五个字看了很久，觉得肩膀上突然多了一份责任。

于是我在群公告下面留言：“以后群里的技术问题，可以统一找我。”

消息刚发出去，群里立刻开始提问。

“大佬，为什么我的电脑打不开？”

“大佬，女朋友不回消息怎么办？”

“大佬，长沙哪家粉好吃？”

我一看，这些问题虽然和前端没有直接关系，但作为前端负责人，格局不能太小。我先回答电脑问题是重启，女朋友问题是道歉，粉的问题是每家都好吃。

群友纷纷表示：“不愧是负责人，前端之外也这么专业。”

那天以后，只要群里有人发“@全体成员”，我就会条件反射地坐直。哪怕消息内容只是“谁有多余的奶茶券”，我也会认真思考这是不是一次对前端负责人的考验。

后来群主让我协助维护群秩序，我立刻接下了这个光荣任务。我的主要工作有三项：提醒大家不要发广告，阻止大家改群名，以及在有人发红包时第一时间维护群内公平。

但我很快发现，前两项根本无法完成。广告发完就撤回，群名每天都在变化，至于红包，只要手速够快，公平自然会降临。

我只好在群里宣布：“本负责人决定，今晚八点统一吹水。”

八点一到，群里果然热闹起来。大家从技术聊到工资，从工资聊到房价，从房价聊到夜宵，最后又回到了“谁请客”这个永恒的前端问题。

我看着不断上涨的未读消息，满意地想：这才是真正的团队管理。
