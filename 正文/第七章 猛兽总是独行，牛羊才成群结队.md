# 猛兽总是独行，牛羊才成群结队

那天晚上，群里突然出现了一条消息：“建议大家少吹水，多学习。”

我看完以后深受触动，觉得这位群友说得非常有道理。于是我第一个响应：“赞同，技术人的时间很宝贵，应该把精力放在提升自己上。”

消息发出去不到一分钟，群里有人问：“那明天晚上还去吃烧烤吗？”

我立刻回复：“学习和烧烤并不冲突，烧烤过程中也可以交流技术。”

又有人问：“那谁负责点菜？”

我说：“我负责整体架构，你们负责具体实现。”

大家一致通过了这个方案。

第二天晚上，我们一群前端开发坐在烧烤摊旁边。刚开始，大家确实讨论了五分钟技术：有人问 Vue 版本，有人问工资，还有人问附近有没有招聘。

五分钟后，话题正式进入正轨。

“你们公司还招人吗？”

“招，但是要求能独立负责项目。”

“那你能独立负责吗？”

“我可以负责把项目交给能独立负责的人。”

这句话一出，全桌哄堂大笑。我趁机举起杯子：“来，为长沙前端行业的未来干杯。”

群里有人拍照发到了群公告下面，并配文：“前端群线下技术交流现场。”

群主问：“照片里为什么每个人手里都有啤酒？”

我解释道：“这是为了模拟高并发场景，每个人都在处理自己的请求。”

群主沉默了很久，最后说：“下次记得把菜单也打码。”

回家的路上，我突然想起那句“猛兽总是独行，牛羊才成群结队”。这句话显然不适合前端群。因为猛兽独行只能看源码，牛羊成群却能获得招聘信息、技术资料、饭局地址和红包提醒。

所以我在群里重新解释：“真正的猛兽，也会为了一个红包暂时加入羊群。”

群里马上有人发了一个两百元的红包。

那一刻，我相信自己对人生又有了新的领悟。
