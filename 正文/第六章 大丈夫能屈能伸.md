# 大丈夫能屈能伸

在前端群里混久了，我逐渐掌握了一门非常高深的技术：如何在群友的吹捧和嘲讽之间灵活生存。

有一天，我在群里发了一张自己写代码的照片。照片里只有半块显示器、三杯奶茶和一个打开的编辑器，但我特意把代码区域放大，让大家看不清具体写的是什么。

很快就有人回复：“鑫鹏大佬又在研究什么高深技术？”

我还没来得及回答，另一个群友说：“看起来像是复制粘贴出来的。”

群里瞬间安静了。

我知道，真正考验我的时刻到了。直接反驳，显得我没有格局；承认复制，又会损害大佬形象。于是我缓缓敲下一行字：“代码不重要，重要的是思想。”

群友纷纷表示受教。

我刚准备松一口气，群主又问：“那你这段代码到底是干什么的？”

我回答：“这是一个比较底层的东西，不方便在群里展开。”

其实我也不知道它是干什么的，因为当时只是打开了编辑器，还没有开始写。

后来，群里开始流行一种游戏：每个人轮流发一句话，其他人必须用专业术语解释。有人说“我饿了”，群友解释为“当前系统资源不足，需要进行能量补充”；有人说“我困了”，群友解释为“浏览器线程进入低功耗模式”。

轮到我时，我发了一句：“我想吃烧烤。”

群友立即开始分析：“这是在表达对夜间社交场景的需求。”“这体现了前端开发者对高并发烟火气的追求。”“建议采用就近原则进行线下部署。”

我看着大家一本正经地胡说八道，十分感动，当即发了一个定位。

有人问：“大佬这是要开技术分享会？”

我说：“不是，来不来？”

十分钟后，群里少了一半的人。剩下的人继续吹水，表示他们正在远程参与。

我终于明白了，大丈夫能屈能伸。需要装大佬时要伸，需要请客时要屈；被人夸奖时要谦虚，被人质疑时要转移话题。至于群友到底懂不懂技术，这并不重要，重要的是大家都能把一句“吃饭了吗”聊成架构设计。
